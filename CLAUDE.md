## Языковые требования
Общаться только на русском языке. Соблюдать PSR. Для каждого метода писать doc комментарии.
Используй mcp Context7 и playwright когда это нужно. Если считаешь, что скачав какую-то библиотеку ты справишся с задачей лучше или код от этого станет лучше, не стесняйся запрашивать установку этих библиотек.

## Техническая архитектура проекта
Это Laravel-проект для создания сайта художника/иллюстратора/дизайнера, построенный на:
- Laravel 12 (PHP 8.2+) 
- Livewire Flux UI компоненты
- Livewire Volt для интерактивности
- Tailwind CSS для стилей
- Vite для сборки фронтенда
- SQLite база данных (для разработки)
- Pest для тестирования

## Основные команды разработки

### Запуск разработки
```bash
composer run dev
# Запускает сервер, queue listener и vite dev server одновременно
```

### Тестирование
```bash
composer run test
# Очищает конфиг и запускает тесты через Pest
```
или
```bash
./vendor/bin/pest
# Прямой запуск Pest
```

### Линтинг и форматирование кода
```bash
vendor/bin/pint
# Laravel Pint для форматирования PHP кода согласно PSR
```

### Сборка фронтенда
```bash
npm run build  # production сборка
npm run dev    # development watcher
```

## Структура проекта

### Backend (Laravel)
- `app/Http/Controllers/` - HTTP контроллеры
- `app/Livewire/` - Livewire компоненты
- `app/Models/` - Eloquent модели
- `database/migrations/` - миграции БД
- `routes/` - маршруты (web.php, auth.php)

### Frontend 
- `resources/views/` - Blade шаблоны
- `resources/views/livewire/` - Livewire компоненты-представления
- `resources/views/flux/` - кастомные Flux UI компоненты
- `resources/css/app.css` - основные стили
- `resources/js/app.js` - JavaScript точка входа

### Конфигурация
- Использует SQLite для разработки (`database/database.sqlite`)
- Livewire Flux требует аутентификации через composer.json credentials
- Настроена для работы с GitHub Actions (lint.yml, tests.yml)
